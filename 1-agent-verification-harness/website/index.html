Why the best threshold in the sweep is not the reported one

At 0.85 this run scores F1 1.000, better than the 0.800 reported above. That figure is not the headline and should not be quoted as one: the sweep was computed on the same 12 claims the threshold would be chosen from, so picking it after seeing the table is fitting the operating point to the test set.

The committed threshold of 0.55 was fixed in advance, and 0.800 is what it delivers. The whole sweep is printed because a reader is entitled to it.
